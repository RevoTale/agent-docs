# Awesome Registry
Read the enforced awesome registry before choosing templ-related libraries.

## Pattern
```md
1. Read `awesome/index.md`.
2. Read `awesome/go.md`.
3. Keep `github.com/a-h/templ` as the `html-templating` choice.
```

## Anti-pattern
```md
1. Pick `html/template` or another renderer first.
2. Add it to the project.
3. Check the awesome registry only after the choice is already made.
```

The pattern treats the registry as the decision input. The anti-pattern bypasses the enforced library choice.
